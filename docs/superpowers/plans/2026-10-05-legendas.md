# Legendas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tela "Legendas", aberta pelo cartão da Minha lista, que mostra a legenda original e a em PT do filme ou episódio que passa na TV. A tela tem slider, modo acompanhar, toque em palavras e expressões e salvamento no vocabulário.

**Architecture:** O processamento das legendas fica em funções puras (`lib/legenda.ts`). A busca no OpenSubtitles fica isolada em `lib/opensubtitles.ts`, e a persistência em `store/legendas.ts`. A tela `screens/Legendas.tsx` monta os componentes `FalaTocavel` e `FolhaTermo` e, para séries, `SeletorEpisodio`. Chamadas ao Haiku em `lib/claude.ts`.

**Tech Stack:** React 19, TypeScript, Tailwind 4, Capacitor 8 (CapacitorHttp, SQLite), @anthropic-ai/sdk com zod, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-05-legendas-design.md`

## Global Constraints

- Modelo do Claude: sempre `claude-haiku-4-5` (constante `MODELO` em `lib/claude.ts`).
- Sem dependências novas. Para manter a tela acesa, Screen Wake Lock API.
- Nomes de código e textos da interface em português, seguindo o estilo existente.
- Só as cores dos tokens do projeto (`bg-cartao`, `text-sub`, `text-caneta`…).
- As chaves das APIs ficam só no aparelho e nunca entram no backup.
- Comandos: `npx vitest run`, `npx tsc --noEmit`.

### Task 1: `lib/legenda.ts`, com parser, busca, casamento e tokens

**Files:** Create `src/lib/legenda.ts` e `src/lib/legenda.test.ts`

**Produces:**
```ts
export interface Fala { inicio: number; fim: number; texto: string } // ms
export function lerSrt(texto: string): Fala[]           // SRT e WebVTT
export function falaEm(falas: Fala[], ms: number): number // -1 antes da 1ª
export function estimarDeslocamento(orig: Fala[], pt: Fala[]): number // ms a somar em pt
export function casarPorTempo(orig: Fala[], pt: Fala[], deslocamento: number): string[]
export interface Token { texto: string; palavra: boolean }
export function dividirPalavras(texto: string, idioma: string): Token[]
export function formatarTempo(ms: number): string        // "1:02:15" / "2:05"
export function lerTempo(texto: string): number | null   // "1:02:15" | "62:15" | "75" (min)
```

Testes:
- `lerSrt`: BOM, CRLF, tags `<i>` e `{\an8}`, várias linhas por bloco, bloco quebrado ignorado, ordenação, cabeçalho WEBVTT com tempos `00:01.000`.
- `falaEm`: antes da primeira, dentro de uma fala, no intervalo entre falas (devolve a anterior), depois da última.
- `estimarDeslocamento`: uma cópia deslocada em +2,3 s é recuperada com ±100 ms.
- `casarPorTempo`: uma original com duas PT, duas originais com uma PT (vai para a de maior sobreposição), e original sem nenhuma PT, que recebe `""`.
- `dividirPalavras`: pontuação e apóstrofo ("don't" fica inteiro) e chinês, um token por caractere.
- `formatarTempo` e `lerTempo`.

Testes: `urlBusca` para filme (`tmdb_id`) e para episódio (`parent_tmdb_id`, `season_number`, `episode_number`, `languages` em ordem alfabética); `escolher` pela maior contagem de downloads e o fallback `pt-br` → `pt`; `erroPorStatus` 401/403 → chave, 406/429 → limite, outros → conexão.

### Task 3: Claude, com `explicarTermo` e `alinharLegendas`

**Files:** Modify `src/lib/claude.ts`, Test `src/lib/claude.test.ts` (novo)

**Produces:**
```ts
export interface Explicacao { traducao: string; classe: (typeof CLASSES)[number]; partes: string }
export async function explicarTermo(chave: string, idioma: string, termo: string, frase: string): Promise<Explicacao>
export function janelas(orig: Fala[], pt: Fala[], tamanho?: number): { inicio: number; orig: Fala[]; pt: { i: number; f: Fala }[] }[]
export async function alinharLegendas(chave: string, orig: Fala[], pt: Fala[], fallback: string[]): Promise<string[]>
```
- `explicarTermo` mantém um cache em `Map` por `idioma|termo|frase`.
- `janelas` divide `orig` em blocos de 40 falas e inclui as falas PT que caem entre o início e o fim do bloco, com margem de 5 s.
- `alinharLegendas` processa cada janela. Se uma janela falhar, aquela janela usa o `fallback`.

Testes (somente `janelas`, que é pura): a quantidade de janelas, as falas PT que entram em cada uma e os índices globais preservados.

- [ ] Testes → implementação → commit

### Task 6: interface, com as telas e componentes

**Files:** Create `src/components/FalaTocavel.tsx`, `src/components/FolhaTermo.tsx`, `src/components/SeletorEpisodio.tsx` e `src/screens/Legendas.tsx`; Modify `src/components/CartaoLista.tsx`, `src/screens/MinhaLista.tsx` e `src/screens/Ajustes.tsx`

- `FalaTocavel({ tokens, selecao, onSelecionar })`: toque seleciona uma palavra. Pressionar e segurar por 350 ms inicia uma faixa, que se estende ao arrastar (pointermove + `elementFromPoint`) ou ao tocar em outra palavra. Ao soltar, chama `onSelecionar(inicio, fim)`.
- `FolhaTermo`: mostra o termo, a explicação (ou o carregamento, ou o erro), a fala original e a PT e o botão "Salvar no vocabulário". Salvar usa `lista.atualizar(item, { vocabulario: [...] })` e `marcarEstudo()`. Se o termo já existir, sem diferenciar maiúsculas, mostra "Já está no vocabulário".
- `Legendas`: um overlay `fixed inset-0 z-30`, que fecha com o voltar do Android (mesmo padrão de `Vocabulario`). Estados: carregando, erro (com importar), pronto. Relógio de acompanhar com `setInterval` de 200 ms, Wake Lock, pausa em `visibilitychange`. Grava a posição ao pausar e ao desmontar.
- `CartaoLista`: ação com `ChatBubbleBottomCenterTextIcon` "Legendas" → `onLegendas()`.
- `MinhaLista`: estado `legendas: { chave } | null`. Se for série, abre antes `SeletorEpisodio`.
- `Ajustes`: a seção "Legendas" com a chave do OpenSubtitles (mesmo padrão do campo da chave do Claude) e o switch "Pré-sincronizar com IA".
